# A three-minute walkthrough

1. Open My work and create a task under a project. Start its timer, then stop and save.
2. Open Timesheet to inspect the session or record past work manually.
3. Open Team reports and compare project, category, and daily totals.
4. Open Opportunities, inspect supporting tasks, and review the disclosed impact assumptions. Record a small pilot measurement with review time included.
5. In Workspace, create a project and inspect the weekly briefing run history. Use Run now to save a brief.

The hosted demo uses synthetic browser records. Run the backend to demonstrate server permissions, SQLite persistence, and scheduled execution. Optional provider calls need your own configured model and key.

## What to explain in an interview

The application controls calculations. The optional model explains scoped facts and cannot issue SQL or execute actions. Cited task IDs must exist. A recurring category is a candidate for investigation, not proof of automatable work. Pilot observations remain separate from estimated impact.
